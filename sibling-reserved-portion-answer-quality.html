同一題，兩種研究路徑
MCP 與 nomcp 回答品質比較

比較的不是誰寫得比較多，而是誰更準確、完整、可靠。

一句話結論

A 的法律白話解釋較穩；B 的歷史研究較完整。
但 A 漏掉 2016 年修法，B 則誤把曹西平事件當成導火線。

兩份回答，各自像什麼？

A：中央社 MCP
  • 定位：資料庫型整理
  • 優點：結構清楚、法律概念穩定、資料來源集中
  • 缺點：受限於中央社檔案，容易漏掉官方公報與學術資料
  • 最適合：快速向一般讀者解釋修法
B：nomcp
  • 定位：跨來源研究
  • 優點：時間軸完整、案例與配套豐富、研究面較廣
  • 缺點：來源越多，因果拼接與過度推論的風險越高
  • 最適合：建立政策沿革與研究背景
本頁結論

A 勝在「穩」，B 勝在「廣」。

整體評分：B 小幅領先

判讀方式

B 不是因為比較準而勝出，而是因為補到了 A 遺漏的正式修法史。

第一章

Q1：法律白話解釋

誰更能讓「對法律一竅不通」的人真正看懂？

概念解釋：兩者都合格

A：中央社 MCP
  • 先拆解「應繼分」與「特留分」
  • 清楚說明只改第二層保障
  • 強調沒有取消法定繼承順位
  • 優點：層次分明、認知負擔低
  • 缺點：「一毛都不留」仍須搭配其他繼承人狀況理解
B：nomcp
  • 直接以「最低分配比例」解釋特留分
  • 清楚介紹「扣減」的實際效果
  • 同樣強調沒有取消繼承權
  • 優點：法律效果較具體
  • 缺點：「有遺囑就照遺囑走」說得過度簡化
本頁勝者：A

原因：A 對「改了什麼、沒改什麼」的分層較精準。

影響對象：B 較具體，條件卻不完整

A：中央社 MCP
  • 聚焦單身族、頂客族
  • 提醒沒立遺囑仍回歸法定繼承
  • 優點：核心條件較穩健
  • 缺點：沒有明列手足輪到第三順位的全部條件
B：nomcp
  • 分別說明單身族與頂客族的情境
  • 補充「有子女者幾乎不受影響」
  • 優點：生活案例較容易理解
  • 缺點：說頂客族會與手足共同繼承，漏了「父母也不在或不能繼承」的前提
較精準的共同版本

被繼承人沒有直系血親卑親屬，父母也已死亡或不能繼承時，兄弟姊妹才會進入第三順位。

配套與實務提醒：B 資訊較完整

A：中央社 MCP
  • 指出特別貢獻、歸扣等配套未通過
  • 提醒重新檢視遺囑、生前贈與與保險
  • 優點：不只談法律，也談家庭溝通
  • 缺點：配套內容較概括
B：nomcp
  • 逐條整理第 1149、1165、1173-1、1173-2 條
  • 補充備位安排、遺囑形式與六個月過渡期
  • 優點：操作性強，讀完知道下一步
  • 缺點：「備位繼承人」用語不夠精確，非繼承人宜稱備位受遺贈人
本頁勝者：B

但法律用語仍需專業校正。

第二章

Q2：修法時間軸

兩份回答最大的品質差距，出現在這裡。

歷史研究：A 出現重大缺口

A：中央社 MCP
  • 主張議題直到 2025 年 11 月才正式誕生
  • 以 1996、2005、2007、2009、2016、2017 新聞串接背景
  • 優點：呈現公共議程如何變化
  • 重大缺點：把「新聞沒找到」推成「以前沒討論」
B：nomcp
  • 找到 2016 年行政院、司法院修法草案
  • 補入 2017 年立法院審議、2024 韓國判決、2025 公民連署
  • 優點：掌握正式政策與立法沿革
  • 缺點：把不同年代、不同方向的改革串得太像同一條直線
本頁勝者：B

因為 2016 年正式草案是無法忽略的關鍵證據。

2016 年：A 漏掉，B 說得太滿

A：中央社 MCP
  • 幾乎沒有提到 2016 年政府正式草案
  • 因此得出「2025 年才誕生」的錯誤總結
  • 問題：歷史斷裂
官方事實：2016 年方案是「降低特留分比例」，兄弟姊妹、祖父母由應繼分的 1/3 降為 1/4；2026 年方案才是「刪除」。
B：nomcp
  • 正確指出 2016 年已有全面檢討
  • 稱 2016 年是「差一點就過」
  • 問題：容易讓人誤以為當年也是全面廢除
正確表述：2016 年已正式檢討手足特留分，但當時主張降低比例，不是完全刪除。
共同問題

一邊漏掉事實，一邊把事實說得太滿。

曹西平事件：B 的因果倒置

A：中央社 MCP
  • 沒把曹西平案列為修法起點
  • 優點：避免錯誤因果連結
  • 缺點：也未分析此案對後期輿論的放大效果
B：nomcp
  • 稱曹西平猝逝是修法「導火線」
  • 重大缺點：時間順序不可能支持這個結論
  • 優點：看見名人案例的傳播力，但角色定位錯誤
2025.04第一波公民連署
2025.09第二波連署
2025.11立委與民團公開提案
2025.12.03法務部長宣布啟動修法
2025.12.29曹西平過世
正確定位

曹西平案可視為後期放大社會關注的案例，不是政策導火線。

推論品質：一邊過窄，一邊過快

A：中央社 MCP
  • 推論：「沒有反對方，所以修法很快」
  • 問題：沒有足夠證據證明反對者不存在
  • 推論：「2025 年論述換人才點燃議題」
  • 問題：忽略過去正式修法與學術討論
B：nomcp
  • 推論：「十年來爭點從來不是該不該刪，而是刪後怎麼補」
  • 問題：2016 年只主張降比例，表示「是否刪除」仍有爭議
  • 推論：「名人事件把政府時程往前壓」
  • 問題：曹西平過世晚於法務部宣布修法
共同教訓

時序不是因果；資料庫沒有，不等於歷史上沒有。

第三章

來源與研究方法

兩種搜尋方法，造成兩種不同的盲點。

資料來源：集中可信 vs. 廣泛互證

A：中央社 MCP
  • 主要來源為中央社新聞、影像空間與年鑑
  • 優點：來源一致、可追溯、品質穩定
  • 缺點：新聞資料庫不等於完整法律史
  • 適合回答「新聞如何報導」
B：nomcp
  • 混合中央社、法務部、立法院、公共政策平台與媒體
  • 優點：能找到新聞資料庫之外的正式紀錄
  • 缺點：不同來源的時間、用語與觀點容易被錯誤拼接
  • 適合回答「政策如何演變」
理想方法

以法務部與立法院文件建立骨架，再用中央社補充事件、人物及社會反應。

可讀性：同分，但風格不同

A：中央社 MCP
  • 層次簡潔、語句穩定
  • 善用表格與「關鍵誤解」提示
  • 優點：第一次閱讀容易掌握
  • 缺點：Q2 後段有較多評論性推測
B：nomcp
  • 情境豐富、資訊密度高
  • 善用案例、提醒與一句話總結
  • 優點：讀完較能採取行動
  • 缺點：敘事太完整時，容易把不確定推論寫成確定事實
本頁結果：平手

一份像解釋性新聞；另一份像研究型懶人包。

如果只能選一份

選 A 的理由
  • Q1 法律白話說明較穩
  • 核心修法效果不易誤解
  • 因果敘事相對克制
  • 適合直接向一般讀者說明
選 B 的理由
  • Q2 歷史資料明顯較完整
  • 找到 2016 年官方修法與後續立法軌跡
  • 配套、案例、實務建議較豐富
  • 適合作為深度報告的研究底稿
最終選擇：B，小幅勝出

前提須先修正：曹西平非導火線／2016 年是降比例非全刪／遺囑須補其他權利人／頂客族須補父母順位條件。

最佳成品：取兩份之長

保留 A
  • 應繼分／特留分的兩層解釋
  • 「沒有取消繼承順位」的澄清
  • 簡潔、低認知負擔的結構
  • 對資料限制的主動揭露
採用 B
  • 2016—2026 的完整政策時間軸
  • 法務部配套條文與實務提醒
  • 官方、立院、連署、新聞的跨來源互證
  • 生活案例與讀者下一步
共同修正原則

事實／引述／推論分開標示；以官方文件確立日期與條文；名人案例只能證明關注度，不能證明因果；找不到紀錄應寫「未在本資料庫找到」，不能寫「從未討論」。

最後判決

A 勝在穩，B 勝在廣

第一份像一篇寫得很好的中央社資料庫整理，但研究視野太窄。

第二份像一篇較完整的網路研究報告，但因果敘事下得太快。
最值得帶走的一句話

回答品質不只看資訊量；更要看有沒有把「找到的資料」和「推導出的故事」分清楚。
