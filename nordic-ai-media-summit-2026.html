02 · Florent Daudens & Nikita Roy

我們把容器誤認為新聞本身

舊假設
  • 把事實報出來就夠了
  • 讀者自己會理解
  • 網站 / 文章格式 = 新聞
  • 首頁是核心產品
新現實
  • 資訊過剩，事實互相矛盾
  • 讀者要的是定位框架
  • 容器隨技術變化，價值不在容器
  • Agent 截走流量，網站不可見
「人們不要事實的新聞，他們要的是意義建構（sensemaking）。」 — Florent Daudens
「如果不依賴網站結構，你會建什麼？」— 這個問題在 Agent 時代更尖銳：
當使用者根本不打開你的網站，你還剩什麼？ — Nikita Roy

  • →媒體需在網站嵌入 Agent 可讀指令，告訴 Agent 如何使用內容

分析使用者透過 chatbot / agent 的提問行為 → 發現真實資訊需求缺口 → 反向決定選題方向
03 · Agent 實作案例 (1/2)

北歐媒體怎麼做：VG Norway

VG X 新 App，以 AI 管理的摘要取代傳統文章。用 clustering algorithm 將文章與影片自動歸組成「故事」，CMS 人工介入極少。
VG Lab 只有「兩個人 + 一組 agents」的小團隊，負責評估新概念的可行性、市場需求、成本、競品——快速驗證，不動主編輯室。
模式：獨立小團隊 → agent 串接多步驟 → 人類仍在關鍵決策節點 → 不干擾原有運作
03 · Agent 實作案例 (2/2)

北歐媒體怎麼做：Bonnier · Polaris · 瑞典

Bonnier 工具名 Flows：讓記者自行組建 agentic 流程，串接研究 → 萃取 → 規劃 → 決策 → 撰寫。實際用途：自動監控新聞線索並摘要，供編輯判斷。
Polaris
Media 使用 agentic workflows 搭配 vibe coding。重點：非工程師記者也能自己建工具——降低技術門檻是核心設計目標。
Aftonbladet
Expressen 瑞典兩大媒體為世足賽開發 chatbot，底層同樣是 agentic workflow——多步驟串接、動態回應使用者問題。
共同特徵：現有人才 + agents 組合 → 小規模實驗 → 不等「夠成熟」才開始
04 · 快艇策略

傳統媒體的「隔離實驗室」模式

  • →Politiken（丹麥）：在傳統編輯室旁設獨立實驗小組，快速迭代不影響主品牌
  • →VG（挪威）：VGX app 與主 app 完全分離，失敗了不傷母艦
  • →Interactive widgets、vibe-coded journalism——有些工具由非工程師記者自行構建
  • →VG Lab 以「2人 + agents」評估可行性，失敗成本極低
「如果不改變，任何新創都能超越我們。」 — Gard Steiro，VG 總編輯
邏輯：不是「等想清楚再做」，而是「先隔離實驗，再擴規模」——降低試錯風險的組織設計。
05 · Rasmus Kleis Nielsen · RISJ 所長

AI 時代的信任悖論

懷疑 受眾對 AI 新聞
普遍抱持懷疑
信任 AI 氾濫後
信任成稀缺資源
品牌 建立信任靠
傳統要素
  • →信任建立靠：品牌、準確性、語言、偏見控制——不是展示技術能力
  • →AI 工具越普及，能分辨真假的受眾越珍貴——新聞室的核心競爭力是核實，不是生產量
  • →Shuwei Fang：市場上層（品牌/信任驅動）vs 下層（基礎設施）—— 中間的傳統媒體最危險
AI 的矛盾：可能讓更多人接觸新聞，也可能讓權力集中在少數平台手中。選擇在媒體機構的戰略決策。

新聞業的危機不是 AI 太強——
是多數媒體還在用舊容器裝新世界。

經濟 市場走向兩極 信任溢價 vs 商品化——居中最危險。
定義 容器 ≠ 新聞 網站是歷史偶然，核心能力才是資產。
Agents 現在就要實驗 等 Agent 成熟再做已經太晚。
實作 2人 + agents 可行 VG Lab 模式：小團隊 + agentic 流程 = 快速驗證。
組織 隔離試錯 快艇策略：新品牌與主品牌分離，降低風險。
信任 技術不等於信任 品牌、準確、偏見控制——這些才是護城河。
