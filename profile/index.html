2023 ～ 2026 生成式 AI 應用到新聞業的 AI 轉型
Multi-Agent Systems

Multi-Agent 新聞工作流系統

主導中央社內部 AI 協作基礎設施設計，從眾多單一 AI 輔助端點，到 agentic workflow，並實作跨機器多 agent 協作機制。以 Discord 讓 coding、editorial、design、evaluator、analyst 等 agent 可在不同機器上穩定接力，將 AI 從單點工具提升為可運營的新聞工作流系統。

MCP / Zero-Click Era

AskCNA MCP Server

因應零點擊時代來臨，主導規劃 MCP Server 與 AskCNA 服務，超前部署 AI agent 中介新聞資訊的時代，確保中央社新聞資料庫不落伍。
